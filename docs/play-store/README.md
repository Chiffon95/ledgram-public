## Product summary

LEDgram turns an Android phone, tablet, or foldable into a customizable full-screen LED message display. The app includes:

- Text + Glow and Dot Matrix rendering
- Solid text color, six static gradients, and four animated gradients
- Bold, italic, underline, and explicit multiline text
- Static, left, and right marquee modes
- Blink, Pulse, and Fade effects with independent motion, effect, and gradient speeds
- A local Saved Displays library with save, load, rename, explicit update, delete, and load Undo
- Sequences that play saved displays in order with independent editing, reordering, repeat, and playback timing
- Local MP4 and GIF export with Standard/High MP4 quality, Low/Medium/High GIF quality, preview, cancellation, MediaStore saving, and Android sharing
- Persistent Editor settings and real-time Preview
- System Default plus 14 bundled selectable languages
- Arabic right-to-left layout support
- Full-screen Display without ads
- Google Mobile Ads with UMP consent and globally non-personalized ad requests
- No account or login requirement
